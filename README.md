# Dream TVs

---

## What's Up

Dream TVs adds craftable TVs to Minecraft. Place one, right-click it, paste a video link, and you're watching. No commands, no operator permissions, no fuss. It's an addon for [Dream Displays](https://modrinth.com/plugin/dreamdisplays), which does the actual impresive video stuff.

Pick from a slim **LCD Panel**, a bezel-free **Jumbotron**, a chunky retro **CRT TV**, or a ready-made **Flat Screen**. Line up LCD Panels or Jumbotrons on a wall and they join into one big screen, and a **TV Remote** lets you run it from the couch. If you have Create, Mekanism, Applied Energistics 2 or other tech mods, the recipes use their items.

---

## What you need

Minecraft 1.21.1, 1.21.11 or 26.3, on Fabric or NeoForge.
[Dream Displays](https://modrinth.com/plugin/dreamdisplays) 1.10.9 or newer.
Install on the server and on every client.
